# Quickstart Guide for Todo Console App

This guide explains how to run the Todo Console App.

## Prerequisites

- Python 3.13 or higher

## Running the application

1.  Navigate to the `src` directory.
2.  Run the main application file:

    ```bash
    python main.py
    ```

## How to use

The application will present you with a menu of options:
1.  Add a new task
2.  View all tasks
3.  Update a task
4.  Delete a task
5.  Mark a task as complete/incomplete
6.  Exit

Enter the number of the option you want to choose and follow the prompts.
